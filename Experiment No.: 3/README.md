# 📊 Retail Sales & Profit Performance Dashboard

## 📌 Project Overview

The **Retail Sales & Profit Performance Dashboard** is an interactive Power BI project developed to analyze retail business performance. The dashboard provides insights into sales, profit, orders, customers, products, categories, and regional performance.

The project combines data from a **MySQL database** and the **Kaggle Sample Superstore dataset**, creating a centralized solution for business analysis.

## 🎯 Objectives

- Analyze sales, profit, orders, and profit margin.
- Identify top-performing customers and products.
- Compare sales across categories, segments, cities, and states.
- Analyze monthly sales and profit trends.
- Provide interactive filters for better analysis.
- Support data-driven business decisions.

## 🛠️ Tools & Technologies

- **Power BI** – Dashboard and data visualization
- **MySQL** – Database management
- **Power Query** – Data cleaning and transformation
- **DAX** – Measures and calculations
- **Kaggle** – Sample Superstore dataset

## 🔄 Project Workflow

1. Created and populated the MySQL `retail_analytics` database.
2. Connected MySQL tables to Power BI.
3. Imported the Kaggle Superstore CSV dataset.
4. Cleaned and transformed data using Power Query.
5. Created relationships and a star-schema data model.
6. Developed DAX measures.
7. Designed interactive dashboards using KPI cards, charts, maps, and slicers.

## 📈 Dashboard Features

### Page 1 – Retail Sales & Profit Performance
- Total Sales
- Total Orders

- Profit Margin %
- Sales by Category

- Monthly Sales & Profit Trends
- Sales by Customer Segment

### Page 2 – Customer & Product Analysis
